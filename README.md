# ARKECH ATELIER

E-commerce premium inspiré de la maquette validée : mode marocaine contemporaine, pièces reworked et séries limitées.

## Démarrage

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000

## Inclus dans cette V1

- Accueil premium responsive
- Boutique + collections
- Fiches produits avec tailles
- Favoris local
- Panier persistant (localStorage)
- Checkout Maroc / paiement à la livraison
- À propos, FAQ, contact
- Design desktop + mobile
- Données produits centralisées dans `lib/products.ts`

## À connecter pour la production

- CMS / base de données produits et stocks
- Authentification client
- Paiement en ligne si souhaité
- Service d'expédition
- Emails de confirmation
- Analytics / Meta Pixel
- Domaine et hébergement

Les images de démonstration utilisent Unsplash. Remplacez-les par les visuels officiels ARKECH avant mise en production.
